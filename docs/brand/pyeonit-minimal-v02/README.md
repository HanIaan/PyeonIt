# 편잇 브랜드 — 선택 시안 v02

2026-11-08. 사용자가 대화에서 가장 마음에 든다고 선택한 미니멀 버전.

## 먼저 볼 파일
- `pyeonit-brand-minimal-v02.png`: 선택한 원본 브랜드 보드. Claude는 이 이미지를 직접 열어 확인한다.
- `CLAUDE-HANDOFF.md`: 웹 디자인에 적용할 때 전달할 요청문.

## 디자인 방향
편입 정보는 정확하게, 브랜드 표정은 능청스럽게. 여백이 많은 미니멀한 화면과 무심한 화살표 캐릭터를 결합한다. B급 감성은 표정과 약간 엉뚱한 실루엣에서 만든다.

- 심볼: 오른쪽으로 꺾이는 두꺼운 화살표 + 반쯤 감긴 두 눈.
- 첫 시안의 머리 위 강조선은 제거한 버전이다.
- 글자: `편잇`. 수평 기준선과 단정한 간격, 굵은 고딕 인상.
- 영문 표기: `PyeonIt`.
- 웹 헤더 권장 조합: 심볼 + 편잇. 영문은 필요할 때만 보조적으로 사용.
- 과한 기울임, 장식선, 스티커 효과, 그림자, 그라데이션을 추가하지 않는다.

## 컬러
아래 HEX를 실제 구현의 기준으로 사용한다. 생성 이미지의 픽셀을 추출하면 미세하게 다를 수 있다.

| 역할 | 이름 | HEX | 적용 제안 |
|---|---|---|---|
| 브랜드 포인트 | LIME | #D7FF3F | 주요 버튼, 선택 상태, 아이콘 강조 |
| 기본 글자·심볼 | INK | #20211D | 본문, 제목, 로고, 라임 위 텍스트 |
| 기본 바탕 | PAPER | #F6F3EA | 전체 화면 바탕 |

미색 바탕과 먹색 텍스트를 중심으로 쓰고 라임은 소량만 사용한다. 라임 버튼에는 먹색 글자를 쓴다. 라임을 밝은 바탕의 작은 본문 글자색으로 사용하지 않는다. 오류·성공·경고 등 기능 색은 이 브랜드 팔레트와 별도로 정한다.

## 글씨체 정보 — 정확한 폰트명이 없는 이유
이 시안은 내장 이미지 생성 도구로 만든 래스터 이미지다. 시안의 한글·영문은 **생성된 레터링**이며 특정 폰트 파일을 적용한 결과가 아니다. 따라서 원본 폰트명, 정확한 웨이트, 자간 수치는 존재하지 않는다. 아래 서체는 구현용 추천이며 원본 사용 서체라는 뜻이 아니다.

### 로고용 대체 후보: Black Han Sans
- 두껍고 덩어리감 있는 한글 인상을 시험해볼 후보. 동일한 형태를 보장하지 않는다.
- 공식 소개: https://fonts.google.com/specimen/Black+Han+Sans
- CSS family 이름: `Black Han Sans`.
- 로고의 인상을 정확히 유지하려면 선택 이미지에 맞춘 별도 벡터 레터링 작업이 필요하다. 후보 서체로 타이핑한 것만으로 원본 로고가 재현됐다고 하지 않는다.

### 웹 UI 추천: Pretendard
- 본문 400, 버튼·라벨 500~600, 제목 600~700을 시작점으로 제안.
- 공식 배포처: https://github.com/orioncactus/pretendard
- UI와 영문 보조 텍스트를 하나의 서체 계열로 정리할 수 있다.
- 로고용 두꺼운 서체를 게시글 본문이나 일정 표 전체에 적용하지 않는다.
- 실제 폰트를 배포할 때는 공식 배포본의 라이선스와 동봉 조건을 확인하고 따른다. 이 패키지에는 폰트 파일이 포함되어 있지 않다.

## 파일의 상태와 적용 범위
- PNG는 브랜드 방향을 설명하는 원본 보드이며, 투명 로고·SVG·파비콘 완성본이 아니다.
- 원본 보드 전체를 웹사이트 헤더에 넣지 않는다.
- 별도 제작 전까지 글자 대체안은 임시안으로 구분한다. 투명 배경이나 벡터 자산이 이미 제공된 것으로 가정하지 않는다.
- 웹 소스, 기존 디자인 작업, 기획 문서는 이번 전달 작업에서 변경하지 않았다.

## 생성 기록
내장 image_gen 도구 사용. 원본 시안을 참조해 다음 취지로 수정했다: 꺾인 화살표와 무심한 눈매 및 세 가지 색상을 유지하고, 강조선을 제거하며, 수평의 단정한 워드마크와 넉넉한 여백을 적용한다. 라임은 작은 아이콘과 포인트에 제한한다. 전체 생성 프롬프트는 `generation-prompt.txt`에 보관한다.
