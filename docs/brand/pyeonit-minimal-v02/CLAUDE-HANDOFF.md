# Claude에게 전달할 요청

`docs/brand/pyeonit-minimal-v02/README.md`를 읽고 같은 폴더의 `pyeonit-brand-minimal-v02.png`를 직접 열어 확인해줘. 이 이미지가 사용자가 선택한 편잇 브랜드 방향이야.

기존 웹 디자인 작업에 이 방향을 반영해줘. 먼저 현재 프로젝트 규칙과 진행 중인 변경을 확인하고 존중해줘.

핵심은 여백이 많은 미니멀한 UI에 무심한 표정의 꺾인 화살표 심볼을 포인트로 쓰는 거야. 색상 기준은 LIME #D7FF3F, INK #20211D, PAPER #F6F3EA이고, 화면은 PAPER와 INK 중심으로, 라임은 주요 버튼과 선택 상태 등에 제한해줘. 라임 위에는 먹색 글자를 써줘.

이미지 속 글자는 AI 생성 레터링이라 정확한 폰트명이 없어. 로고용 대체 후보는 Black Han Sans, UI 추천은 Pretendard야. 대체 서체를 원본 사용 서체라고 설명하지 말아줘. 원본의 심볼과 글자 형태를 유지할 최종 로고는 별도 벡터 자산이 필요하고, 이 폴더에는 브랜드 보드 PNG만 있어. 보드 전체를 헤더 이미지로 넣거나 SVG/투명 로고가 이미 있다고 가정하지 말아줘.

헤더는 심볼 + 편잇 조합을 기본으로 검토해줘. 장식선, 과한 기울임, 스티커 효과, 불필요한 그림자나 그라데이션은 피하고, B급 감성은 로고 표정에 남겨줘. 읽기 쉬운 공고·일정·게시판 구성을 우선해줘.
