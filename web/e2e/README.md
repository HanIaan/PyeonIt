# Q1 통합 E2E

공유 통합 서버를 시작하거나 종료하지 않는다. Chromium만 사용하며 목/네트워크 가로채기는 사용하지 않는다.

```sh
cd web
npm ci
npx playwright install chromium
npx playwright test
npm run lint && npm run build
```

`npm run e2e`도 동일하다. 기본 주소는 웹 `http://localhost:3000`, API `http://localhost:8081`이며 `E2E_WEB_URL`, `E2E_API_URL`로 덮어쓴다. 실행 중인 웹의 API 설정/CORS도 해당 주소에 맞아야 한다. 웹 dev 로그인 활성화와 백엔드 dev 프로필이 필요하다.

계정 닉네임·글·댓글에 실행별 접미사를 붙인다. 생성한 계정/글만 변경하며 기존 데이터 개수/고정 ID를 단정하지 않는다. 학교·공고·일정은 실행 시 API에서 탐색하고, 데이터 부재는 skip/coverage 주석으로 남긴다. 읽기 검증용 글과 dev 계정 등 실행 데이터는 DB에 남는다. 작성자는 정지 상태에서 탈퇴한다.

단계 실패를 모아 마지막에 실패 처리하므로 이미지 오류 이후에도 신고·제재·탈퇴를 검증한다. 글쓰기 UI 자체가 실패하면 후속 검증용 글만 API로 생성하고 원래 실패 및 fallback 주석을 유지한다. 제품 버그를 통과 처리하거나 예상 실패로 숨기지 않는다.

결과 JSON은 `test-results/results.json`, 실패 스크린샷/trace는 `test-results/` 아래에 저장한다. trace에는 세션 정보가 포함될 수 있으므로 커밋하지 않는다. `npx playwright show-trace <trace.zip 경로>`로 확인한다. HTML 리포트의 생성 JS가 현재 ESLint 대상이 되는 것을 피하기 위해 기본 리포터는 list+JSON이다.

## 검증 결과

Chromium 통합 실행: **4 통과 / 1 실패 / 0 건너뜀**. 반복 실행에서도 같은 제품 버그만 재현되었다.

- 통과: 닉네임 변경/30일 UI·API 제한, 공고 필터, TO 계층/미선발, 일정과 월 이동, 관심학교 추가·해제 후 새로고침, 일반 회원 관리자 차단, 비로그인 글쓰기 로그인 안내.
- 실패: `Q1-4 커뮤니티 → 신고 → 관리자 처리·정지 → 탈퇴`의 이미지 실제 로딩 단정(Q1-001).
- Q1-4 후속 단계 통과: 학교 태그 2개, 댓글/답글, 답글의 답글 UI 미노출 및 API 422 `REPLY_DEPTH_EXCEEDED`, 추천 토글, 별도 USER 신고/중복 안내, ADMIN 신고 RESOLVED·숨김 및 공개 API 404, SUSPEND 등록, 기존 정지 세션의 읽기·쓰기/추천/신고 UI 및 API 403 `ACCOUNT_SUSPENDED`, 정지 중 탈퇴.
- `npm run lint && npm run build`: 통과. 앱/백엔드 코드는 변경하지 않았다.

## 제품 버그 목록

1. **Q1-001 — 업로드한 커뮤니티 이미지가 표시되지 않음**
   - 재현: dev USER 로그인 → `/community/write`에서 정상 PNG 업로드 및 학교 태그 2개 선택 → 등록 → 글 상세 확인.
   - 기대: 업로드한 이미지가 편집 미리보기와 글 상세에서 정상 표시된다.
   - 실제: `POST :8081/api/post-images`는 201, 응답 URL은 `/api/post-images/files/<key>.png`. 브라우저는 이를 `:3000`으로 요청해 404가 발생하고 `naturalWidth=0`이다. 같은 경로를 `:8081`에서 요청하면 200이다. PNG 자체는 Chromium의 data URL에서 정상 디코딩된다.
   - 영역 후보: **F3**(커뮤니티 이미지 URL 처리), **B3**(이미지 URL 반환 계약), **C0**(웹/API 경로 연결). 심각도: **중**.
   - 분류: **제품 버그**. `Q1-001` 메시지와 HTTP 증거 첨부를 남기고 테스트는 실제 실패 상태로 유지한다. 수정하지 않았다.

## 테스트 문제와 검증 공백

- 초기 선택 상자 로케이터 오류와 직접 API 쓰기의 CSRF 누락은 테스트 문제로 수정했다. 루트에서 잘못 실행한 명령은 검증 결과에서 제외했다. 이후 검증 명령은 모두 `web/`에서 실행했다.
- HTML trace 리포트의 생성 JS를 ESLint가 검사하던 테스트 구성 문제는 list+JSON 리포터로 해결했다. 앱 ESLint 설정이나 lint 스크립트는 바꾸지 않았다.
- 가입 최초 닉네임 설정: dev 로그인은 이미 가입한 회원 세션만 생성하므로 pending 가입 세션에 도달할 수 없어 검증 불가.
- RANGE 원문: 현재 실제 모집인원 응답에는 EXACT 168개, NOT_RECRUITING 115개가 있고 RANGE가 없다. RANGE 단정 코드는 포함했지만 이번 환경에서 실행되지 않았다. 공유 모집요강을 변경해 데이터를 만들지는 않았다.
- 정지 중 탈퇴는 검증했다. 탈퇴 후 동일 소셜 계정 차단은 dev 계정에 소셜 식별자가 없어 검증 불가. dev 로그인은 닉네임으로 조회/생성하고 역할·정지 여부를 요청값으로 덮어쓰므로 소셜 재가입 차단을 검증하는 수단이 될 수 없다.
